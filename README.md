## ✨ Features
- **Task & Routine Scheduling**: Plan daily tasks, organize schedules by morning, afternoon, evening, and night.
- **Interactive Calendar & Timeline**: View and manage tasks dynamically across dates.
- **Alarm & Notification System**: Supports exact alarms (`SCHEDULE_EXACT_ALARM`) and full-screen alert views for urgent schedule items.
- **Home Screen Widgets**: Quick-access schedule widgets available in multiple sizes (1x2, 2x2, 4x4).
- **Themes & UI Polish**: Dark/light theme support, glassmorphism UI styling, and custom animations.
